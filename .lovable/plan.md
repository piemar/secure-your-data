# MongoDB Heist — Promotional Trailer Video

## Overview

A 25-second Remotion-rendered MP4 trailer pitching MongoDB Heist to sales leadership. The video explains what the platform is, why it matters, and drives excitement to adopt it for GameDay events.

## Creative Direction

- **Vibe**: Tech-thriller meets MongoDB brand — dark backgrounds, MongoDB green (#00ED64) as the dominant accent, cinematic pacing
- **Palette**: MongoDB Forest Green `#00ED64`, Dark Terminal `#061a14`, Off-white `#E8EDDF`, Muted Green `#1a3d2e`
- **Fonts**: Space Grotesk (headers) + JetBrains Mono (code/terminal text)
- **Motion style**: Kinetic typography with snappy springs, terminal-style text reveals, glitch accents
- **Motifs**: Scanline overlays, terminal cursors, matrix rain dots, mission card UI mockups

## Scene Breakdown (7 scenes, ~25s at 30fps = 750 frames)

### Scene 1 — Hook (0-3s, 90 frames)

**"What if learning MongoDB... felt like a heist?"**

- Black screen, terminal cursor blinks, text types out character by character
- Subtle matrix rain in background
- Glitch transition out

### Scene 2 — The Problem (3-7s, 120 frames)

**"Developers  need hands-on MongoDB skills. Docs and slides aren't enough."**

- Split layout: left side shows a boring slide deck icon (faded), right side shows an engaged developer
- Stats fly in: "25 scenario-based missions", "Real MongoDB queries"
- Quick cut transition

### Scene 3 — Platform Reveal (7-12s, 150 frames)

**"Introducing MongoDB Heist — GameDay Edition"**

- Big kinetic typography: "MongoDB" in glowing green, "HEIST" slams in with spring bounce
- Subtitle fades in: "A gamified training platform for SEs"
- The turtle mascot slides in from the side

### Scene 4 — Feature Showcase (12-17s, 150 frames)

**Rapid-fire feature cards staggering in:**

1. "25 Missions" — CRUD, Aggregation, Sharding, Encryption, Vector Search
2. "3 Difficulty Tiers" — Guided → Challenge → Expert
3. "Live Code Editor" — Monaco-powered with inline hints
4. "Chaos Events" — Random disruptions that test adaptability

- Each card springs in with a slight delay, terminal-style borders

### Scene 5 — Engagement Hook (17-20s, 90 frames)

**"Leaderboards. XP. Achievements. Compete as a team."**

- Leaderboard mockup animates in with player ranks filling
- XP counter ticks up rapidly
- Achievement badges pop in with bounce

### Scene 6 — The Why (20-23s, 90 frames)

**"Every mission maps to a MongoDB POV proof."**

- Clean layout: mission names on left, POV capability tags on right, lines connecting them
- Reinforces this isn't just a game — it's strategic training
