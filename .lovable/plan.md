
# MongoDB Heist: GameDay Platform

## Concept
A **"Data Heist"** themed gamified challenge platform where developers play as operatives completing MongoDB scenario-based missions. Think mission control meets cyberpunk — urgent, immersive, and competitive.

## Pages & Layout

### 1. Landing / Login Page — "Jack In"
- Cinematic dark green terminal-style entry screen with glitch animation
- ASCII art MongoDB logo, "INITIATING CONNECTION..." typing effect
- Player name entry with a hacker handle generator
- Pulsing green "CONNECT" button
