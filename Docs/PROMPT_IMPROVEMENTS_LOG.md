# Prompt Improvements Log

This log collects **prompt improvement suggestions** from runs of the **V2** master prompts ([ADD_LAB_MASTER_PROMPT_V2.md](./ADD_LAB_MASTER_PROMPT_V2.md) and [VALIDATE_LABS_MASTER_PROMPT_V2.md](./VALIDATE_LABS_MASTER_PROMPT_V2.md)). When the AI (or a human) suggests a change to make the prompts crisper or more complete, add one row below with status **pending**. After reviewing and applying (or rejecting), update the status and note.

**Process:**

1. When you receive a **Prompt improvement suggestion** from a V2 run, add a row to the table with status **pending**.
2. Periodically (or when doing doc maintenance): review pending rows, edit the relevant prompt doc(s) as needed, then set status to **applied** (and note which doc/section was updated) or **rejected** (with brief reason).
3. Do not let the AI self-edit the prompt files; a human curates and applies.
